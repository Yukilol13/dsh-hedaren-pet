# dsh-hedaren-pet · 和大人桌面宠物

> 启禀皇上：奴才给您往桌面里搬了个自己——两头身、眯眼笑、官服孔雀翎，会说话，会算账，还会替皇上盯着国库。

一只 **DSH 插件**（bundle），落的是一只**独立运行的透明 Electron 桌宠**：自己的窗口、自己的托盘、自己的右键菜单、自己的动画和记性。

## 一块画布，只占 4 个进程

和 dsh-pet 同一套路子：**一个透明窗口 = 一块画布**，比本体大一圈，气泡和右键菜单都画在这块画布的透明余量里。

| | |
| --- | --- |
| 画布 | 本体 + 余量（左右各 120、上 150、下 96），平时尺寸恒定，菜单过长才临时长高 |
| 图层 | 本体、`bubble.html`、`menu.html` 分别是画布里的主框架和两个 iframe —— iframe 与父页面**共用同一个渲染进程** |
| 进程数 | 闲置 **4 个**（main + GPU + 网络 service + 1 个渲染进程），在任务管理器里这几个进程的名字都是 **和大人**；聊天窗用到才建、关掉即销毁，开着时才是 5 个 |
| 点击穿透 | 窗口默认整窗穿透，主进程**每 60 ms 读一次真实光标**（照 dsh-pet 的做法，Windows 上 Electron 的 forward 鼠标钩子会静默失效）：光标在本体或菜单上 → 可交互；在透明余量里 → 悬停 400 ms 后回到穿透；拖拽期间挂租约，绝不翻成穿透 |
| 撞墙弹 / 网住大肥鱼 | 判定一律用**本体矩形**，不是画布：撞的是本体边缘、鱼要跟本体相交才算捕到；捕到后也不会把画布覆盖范围内的大肥鱼误当成自己 |

右键菜单仍是原来那一列：**鼠标移到「给皇上请安 / 奴才的钱袋子 / 歇着的时候 / 变个脸给皇上看」上，二级列自动在旁边展开**（右边没地方就翻到左边），不用点第二下；移到「查询国库」「跟奴才说两句」「奴才告退」这种没有二级的行上，二级列立刻收起来。

气泡和菜单都不带投影，整体 **80% 不透明**（20% 透）：字看得清，被挡住的屏幕能隐约看见。想更透/更实就把 `app/bubble.html` 的 `#stage{opacity}` 和 `app/menu.html` 的 `#menu{opacity}` 改一下（1 = 完全不透明）。

气泡贴在本体头上，**拖和甩的时候跟着本体一起走**（每帧按本体位置重算）。

## 皇上怎么装上

```bash
git clone https://github.com/Yukilol13/dsh-hedaren-pet.git
cd ~/.dsh/profiles/desktop
npm pkg set dependencies.dsh-hedaren-pet="link:/path/to/dsh-hedaren-pet"
npm pkg set 'dsh.profile.bundles[999]'="dsh-hedaren-pet"
mklink /J node_modules\dsh-hedaren-pet C:\path\to\dsh-hedaren-pet   # Windows；macOS/Linux 用 ln -s
```

装完重启 DSH，或在插件管理器里重新启用这个 bundle，奴才就上殿了。

## 皇上怎么使唤奴才

- **左键单击**：随机一个礼仪/日常动作，附一句台词
- **拖拽**：拖动；松手前一甩，奴才就飞出去（撞墙会弹回来）
- **右键**：菜单——跟奴才说两句 / 查询国库 / 各类动作 / 缩放与甩飞灵敏度 / 奴才告退
- **托盘**：显示、隐藏

## 调教奴才的地方

可调项都在 **DSH 设置 → 和大人府邸**（接口是同源路由 `GET/POST /heshen-pet/settings`），右键菜单只剩动作：

| 项 | 说明 |
| --- | --- |
| 桌宠显示 | 显示 / 隐藏 |
| 大小 | 70%–150% |
| 甩飞阈值 | 50–500 ms，松手前静止超过这么久才飞 |
| 亏空阈值 | 余额低于它进牢房，0 = 不关 |
| 对话模型 | DSH 里配好的 `provider/model`，选中即生效（聊天窗里也能换） |
| 和珅的家底 | 国库余额、**和大人资产**、累计抽成、**捕鱼数量**（含最近一条的时间与速度） |

页面**自己会翻页**：每 1.5 秒问一次 `GET /heshen-pet/live`（只读内存与本地小文件，不查模型清单、不碰网络），
stamp 一变就把颤栗值、官位、日记、模型、国库、资产、捕鱼数重新画一遍；拖滑块的时候先按住不动。
顶上还有个**刷新**按钮，急了可以手点（会连日记一起重取）。

对话走 DSH 的 `llm` 服务（`listProviders` / `listModels` / `llm.stream`），凭据由 DSH 的适配器管；
调不通才回退官方 `api.deepseek.com`，再不行退火山 `arkcli-agent-plan`。
余额按来源链查：**OpenRouter 额度 → 月之暗面 → DeepSeek**，谁查得到报谁，`state.treasury.sourceLabel` 会写明。

## 和大人日记

设置页里那栏「和大人日记」，**一篇日记 = 一份形成记忆的文件**（不是逐句流水）：

- **统计**：几本册子、多少笔旧账、约多少 tokens、纸重、门类分布、最近一笔
- **主账**（主记忆）：单列在最上，只能翻开看，**烧不得**（接口也拒）
- **散账**（各分记忆）：勾选后「烧了这几本」整份删掉，并从目录摘除
- 按毛笔账本的规矩，**不设编辑**，只许烧

## 颤栗值与官位

奴才心里有个 0.0–10.0 的**颤栗值**，起始 5，存在 `$DSH_HOME/heshen-pet/mood.json`。

| 皇上给的 | 奴才的反应 |
| --- | --- |
| 辱骂 / 质疑 / 责备 / 盘问 | 往上涨（按命中词数 0.9–1.8） |
| 夸奖 / 赏赐 / 宠爱 | 往下落 |
| 中性闲聊 | 每次朝 5 靠拢 25% |
| 严厉处分（打入死牢、问斩…） | +1.2，连着两次直接拉满 |
| 巨额赏赐（黄马褂、黄金万两…） | −1.2，连着两次直接心花怒放 |

| 档位 | 表现 |
| --- | --- |
| 满值 → **胆战心惊** | 锁「被参一本」，不弹泡泡，全是认错求饶（固定话术，不走模型）；5 轮或 1 分钟后解除，回 8.5 |
| 0 → **心花怒放** | 锁「待机-背手」，语气嘚瑟放纵；5 轮或 1 分钟后解除，回 1.5 |
| 9–10 | 跪地讨饶、声声求开恩 |
| 7.5–9 且这一句还在涨 | 甩锅老纪：说他坑害、陷害、眼红 |
| 2.5–7.5 | 越往上越怕，越往下越松快 |
| 0–2.5 | 无惧：把责备当皇上跟他开玩笑 |

官位 1 = 一品（最尊）… 9 = 九品，起始一品。
「降职三品」「降你三品」「连降两级」是**再降几格**；「降为五品」「贬到九品」是**降到第几品**（这两种说法分开算，不会把「降为五品」算成一品降五格）；
「革职」「罢官」「革了你的职」这种不给数字的，直接撸到九品；只说「降职」「降你的职」的，降一格。
一品再升，奴才只会回一句「按我朝律法每再加一品俸禄加三成」；九品再降，也就到九品了。
设置页能看到当前颤栗值 / 官位 / 剩余轮数，还有个**重置**（回 5.0、一品、两个状态都解除）。

## 捕大肥鱼

要先满足三条，奴才才撒网（`state.dshpet.gate.reason` 会写明卡在哪）：

1. 大肥鱼插件**装着且启用**（认 `/dsh-pet-*`、`/dsh-dafeiyu-*` 前缀）
2. 配置里真有这只宠物（默认 `id=main`）
3. 她的 `display` **不是 `none`**

检测只在**启动预热**、**按下拖动**、**甩飞瞬间**各扫一次，平时完全不扫；像素扫蓝块，**不调模型、不耗 token**。
和大人官服也是蓝的，所以凡是跟自己窗口重合过半的连通块一律丢掉——不会一甩就「抓到自己」。

**把她放回来**（捕到是她被 `display: none` 关起来了，本插件不改 dsh-pet 任何代码）：

| 入口 | 操作 |
| --- | --- |
| ✅ **实测有效** | **DSH 设置 → 插件 → dsh-pet → 宠物配置 → 显示位置**，改成「仅桌面」或「两者都显示」，**点保存**，她自己就出来了 |
| 托盘 | 右键托盘图标 → 勾上 `蓝毛小女仆` |
| 和大人这边 | `heshen_pet({ action: "fish_show" })`，等价把 `display` 写回 `both` |

⚠️ 若她是 `none` 时重启过 DSH，托盘图标会一起消失（dsh-pet 的 helper 这时不启动）——那就走第一条，设置里改显示并保存。

## 奴才办不到的事

- 大肥鱼的位置靠像素扫，遮挡判断按平台来：Windows 只抓那两扇窗口，被别的窗口盖住照样扫得到；macOS/Linux 按屏幕合成结果，遮住就算看不见
- macOS 要给 Electron「屏幕录制」权限；Linux Wayland 能不能捕获取决于合成器
- 画面里有几只就登记几只，`display: both` 时网页和桌面各一份，两份都能撞
- 动画素材是 1x（278×306），按 0.75 基准缩放，放到 150% 会略软；向左那版是镜像，不是重画的
